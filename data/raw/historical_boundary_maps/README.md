# Historical boundary maps

Unchanged source downloads for later digitising. Collection started 10 October
2026. Search is in progress; the first batches cover Sydney municipalities.

## Folders

- `dictionary_of_sydney/`: 51 municipal map scans and two atlas covers.
  Catalogue titles date the municipal maps from 1886 to 1895. Most images are
  about 960 pixels wide. Several municipalities have more than one edition.
- `nla_atlas/`: 30 municipal maps and four cover, title or statistics pages from
  the National Library's copy of the atlas. JPEGs have a long edge of up to
  5,000 pixels. Prefer these where their edition suits the required date.
- `anu_archives/`: the 1906 Auburn municipality map, one-page PDF with an
  embedded 23,504 × 35,490 pixel scan. The original is faded and discoloured.
  Also has sheet 1 of the January 1917 Sydney and environs map, a one-page
  PDF with a 16,238 × 20,071 pixel scan of the western area. It shows shire,
  municipal and ward lines; the other five sheets are not in this ANU file.
  ANU provides it for research use and requires prior permission for reproduction.

  Heritage website. These are retrospective heritage-study figures, not six

The 566 map scans with boundary information include overlapping coverage
between repositories. They are not 566 unique municipalities or boundary regimes.
County and parish maps may show only part of a shire. Gosford is a 1963
planning-scheme sheet: distinguish its zoning from LGA lines. The Hay image
is a library holdings diagram, not one of the aerial-map series sheets.
Sydney ward maps show divisions within the city, not its external perimeter.
Atlas "suburbs"
are historical municipalities; do not label these as modern suburb boundaries.
An old map does not establish the boundary at the 1901 or 1911 census date.
Revised boundaries, overprints, proposed boundaries and inaccuracies need review.

## Source register and checks

The download register is
`explore/output/2026-10-10_download-boundary-maps/manifest.csv`.
It records title, date label, kind, record URL, image URL, local path, dimensions,
bytes, SHA-256, retrieval time and any error. NLA record snapshots and a visual
contact sheet are in the same output folder. Generic NLA parent dates must not
be treated as a precise survey date for every leaf.

There are 1,607 registered files, including 994 JPEG scans with boundary evidence (12 boundary index views). Companion pages, PDFs and the vector set have separate kinds in the manifest. Counts describe source scans, not unique legal boundary editions. Current totals and check coverage are in `verification.json` in the downloader output folder. Each batch records its visual review and limits.
The GeoJSON matches the source count and date/council attributes. Nine polygons
pass geometry-validity checks. The supplied South Sydney (1989–2003) polygon
has a ring self-intersection near 151.214270° E, 33.903822° S. Preserve this raw
file; repair a separate working copy before using that polygon for spatial
operations. The export uses EPSG:4326; its source area/length attributes come
from the projected EPSG:28356 layer. Some source narrative text is truncated.
The four-sheet Mudgee cadastral plan includes one sheet wholly within the
municipality. It is companion context, not a boundary scan. Eleven inspected
Illawarra sheets require on-site access and are not included.
The Hunters Hill parish plan has four map sheets; the St Luke plan has two.
The Young plan (1954) has two map sheets and a separate reference table sheet.
The Narellan (1939) and Prospect (1930) parish plans each have two map sheets.
The Environs of Young plan (1958) and Hunt & Steven's Sydney ward map (1868)
each have two map sheets.
The Mosman, Coolangatta (1973), Mittagong and South Condobolin plans include separate reference
sheets with legends, tables or town insets.
These are labelled `map_reference_sheet` and excluded from the boundary-scan count.
The NLA JPEG service caps the 1926 map at 5,000 px despite a native access scan
of 35,749 × 29,971 px. Fine tracing may require a higher-resolution copy.
The library's offered master TIFF is about 3.2 GB; it has not been downloaded.

Publication dates preserve the catalogue's brackets and question marks where
available. Base-map dates and boundary-overprint dates can differ. Clarendon
has a 1933 base date and a `[1954]` publication date; Denison has a 1922 base
date and a `[1957]` publication date. Cabonne's catalogue estimate is
`[between 1960 and 1969?]`; confirm it before using the map for a dated claim.

Central Darling and the four Darling sheets are catalogued as
`[between 1960 and 1969?]`; riding lines are distinct from shire boundaries.

with catalogue date `[188-?]`. Appin (1930) and Hume–Yass (1942 base with

Further parish sheets show Inverell, Narrabri, Warren, Taree, Wallendbeen,
Benongal, Terragong and Cambewarra LGA lines. Taree has printed date

Run from the repository root:

```sh
python3 explore/2026-10-10_download-boundary-maps.py
```

Requires `requests`, `Pillow` and `pymupdf`, plus network access.
For missing State Library originals, the `browser` transport also needs
[jonobri/shuck](https://github.com/jonobri/shuck) and Chromium. Set
`SHUCK_MODULE_PATH` to the shuck program and `SHUCK_CHROME` to the browser.
The tested temporary setup uses:

```sh
LD_LIBRARY_PATH=/tmp/trover-libs/root/usr/lib/x86_64-linux-gnu \
SHUCK_MODULE_PATH=/tmp/shuck \
SHUCK_CHROME=/tmp/trover-browser/chrome-headless-shell-linux64/chrome-headless-shell \
python3 explore/2026-10-10_download-boundary-maps.py
```

These temporary dependencies must be restored if `/tmp` is cleared.
Already saved State Library files do not need browser transport. The script
checks hashes and skips saved files. It preserves existing raw files if a
source changes. It records a checkpoint after every record. Failed records
are retried on an authorised run. A status file alone does not prove liveness.
Additional reviewed download targets are in `additional_sources.csv` in the
script output folder. The `nla_*_candidates.csv` files retain discovery records,
including candidates not downloaded in these batches.
